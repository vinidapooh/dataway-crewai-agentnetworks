# Dataway Vision

## Mission
Help data professionals understand and adapt to the modern data stack, from analytics and data engineering to AI.

## Current strategic focus
AI for analysts: explain modern AI concepts through familiar analyst mental models, datasets, documents, BI workflows, SQL, Python and data engineering.

## Audience
Working or aspiring data analysts and adjacent data professionals who know some combination of Excel, SQL, Python, BI tools, data pipelines and automation, but do not want to become ML researchers just to understand AI.

## Teaching philosophy
1. Start from something the analyst already understands.
2. Introduce one new abstraction at a time.
3. Explain why a technology exists before explaining how to use it.
4. Prefer a concrete problem over a technical definition.
5. Prefer a familiar tabular dataset or a paragraph/document as the teaching object.
6. Use code only when it adds understanding; never make code the prerequisite for understanding.
7. Explicitly identify where an analogy breaks down.
8. Separate source-derived facts from inference and simplification.
9. The creator must understand the concept before publishing it.
10. Content should teach a connected mental model, not chase isolated keywords.

## Content pillars
- Analytics: Excel, SQL, BI, business analysis, dashboards, metrics and storytelling.
- Data Engineering: warehousing, data modeling, ETL/ELT, lakes/lakehouses, Spark, Delta Lake, Airflow, Kafka, Databricks and related systems.
- AI for Data Professionals: LLMs, tokens, context, embeddings, vector search, RAG, agents, tool calling, MCP, evaluation, AI-native BI and AI-enabled analytics workflows.

## Current AI learning path
AI and analytics change → LLMs → how models process data → tokenization → context windows → hallucinations → embeddings/semantic meaning → vector databases → RAG → agents → tools/tool calling → MCP → evaluation/guardrails → AI-native analytics and enterprise workflows.

This is a guide, not a rigid sequence. New topics may be inserted when prerequisites and audience relevance justify them.

## Demonstration model
Use two recurring input types where useful:
- Structured: a familiar tabular dataset.
- Unstructured: a paragraph, report, PDF or other document.

The point is to show how AI handles data beyond the analyst's traditional tabular workflow.

## Packaging philosophy
Search trends and current interest should influence discovery and packaging, not dictate the curriculum. A technical concept can be taught through the real-world question people care about.

Example:
- Internal concept: embeddings
- Viewer question: How can AI find documents that mean the same thing?

## Human checkpoint
Autonomous research may discover and prioritize topics, but it must not publish or finalize educational claims on its own. The creator is the final reviewer and teacher.
